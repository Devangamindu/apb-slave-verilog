# APB Slave Interface in Verilog

## Overview

Designed and verified an AMBA APB Slave interface in Verilog HDL for simple memory-mapped peripheral communication.

## Features

- APB setup phase handling
- APB access phase handling
- Read operation
- Write operation
- Address decoding
- Register-based data access

## Concepts

- AMBA APB protocol
- Peripheral bus interface
- FSM design
- Memory-mapped registers
- Synchronous RTL design

## Verification

Verified APB read and write transactions using Xilinx Vivado simulation and waveform analysis.

## Tools

- Verilog HDL
- Xilinx Vivado
